# Cosmos reference implementation

Reference inspected live on October 3, 2026: https://www.cosmos.so/

Alchemy uses the reference's centered sans-serif headline, floating photographic cards, rounded controls, wide galleries, sparse navigation, generous whitespace, and a quiet neutral background. The trial workflow, sources, metric rules, and commercial records remain Alchemy's own.

Original illustrative image asset: `public/art/alchemy-gallery.png`. Generated with the built-in imagegen tool. Prompt: a six-cell editorial photographic contact sheet featuring a sunlit neighborhood café, cobalt ceramic objects, a leafy studio plant, espresso with a red notebook, a timber studio desk, and oranges on lavender linen. Equal cells, natural material texture and light, no people, text, logos, watermark, or website UI. Each cell is framed using CSS background positioning; no Cosmos photographs were copied.

Imagery and the café scenario are illustrative. They do not establish actual customer adoption, impact, measured performance, or a sale.

The hero's float animation and explanatory section movement use Anime.js scopes with cleanup. Reduced motion disables the animations. Text remains readable when animation or JavaScript is unavailable. Native anchors and actual route links work without simulated interaction. Search filters fictional customer records; journey tabs switch explanatory content and support arrow/Home/End keys.
